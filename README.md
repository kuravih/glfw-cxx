# glfw-cxx

glfw-cxx is a Modern C++, Object Oriented wrapper for [GLFW3](https://www.glfw.org/).
Forked from from [glfw-cxx](https://github.com/GenuineAster/glfw-cxx).

## Overview

Instead of working directly with GLFW's C API, this library allows you to use idiomatic C++ classes and methods, making it easier and more intuitive.
This wrapper provides:
- Type Safety: C++ type system instead of C's pointer-based API
- Ease of Use: Object-oriented design patterns familiar to C++ developers
- Resource Management: RAII (Resource Acquisition Is Initialization) principles for automatic cleanup
